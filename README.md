# ☕ Brew & Bloom — American Coffee Shop

> **A modern, cozy and responsive American coffee shop website built with HTML, CSS and JavaScript.**

Brew & Bloom is a premium café website concept designed to give visitors a warm, welcoming and memorable online experience. The website combines an elegant coffee-shop aesthetic with modern frontend development, beautiful food photography, customer reviews, menu highlights, café videos and clear calls-to-action.

The project is designed around the complete customer journey:

**Discover → Explore → Trust → Experience → Visit**

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/brew-and-bloom-coffee-shop.git
```

### 2. Open the Project

```bash
cd brew-and-bloom-coffee-shop
```

### 3. Run the Website

You can simply open:

```text
index.html
```

Or use **VS Code Live Server**:

```text
Right Click → Open with Live Server
```

No Node.js installation or build process is required.
